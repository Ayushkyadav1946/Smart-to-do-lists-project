# 📝 Smart-to-do-lists-project

A modern, intelligent to do list application that helps you organize your tasks effectively with smart features and an intuitive user interface.

## ✨ Features

- ✅ **Create & Manage Tasks** - Easily add,edit, and delete tasks
- 🎯 **Priority Levels** - Set task priorities (High, Medium, Low)
- 📅 **Due Dates** - Assign deadlines to your tasks
- 🏷️ **Categories** - Organize tasks by different categories
- ✔️ **Task Completion** - Mark tasks as complete with visual feedback
- 🎨 **Modern UI** - Clean and responsive design
- 💾 **Local Storage** - Persist your data in the browser
- 🔍 **Search & Filter** - Easily find tasks by keywords or status

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome,Firefox,Safari,Edge)
- No server or backend required

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Ayushkyadav1946/Smart-to-do-lists-project.git
   cd Smart-to-do-lists-project
   ```

2. **Open in browser**
   - Double-click `index.html` or
   - Use a local server:
     ```bash
     python -m http.server 8000
     # or
     npx http-server
     ```

3. **Access the application**
   - Open `http://localhost:8000` in your browser

## 🎯 How to Use

1. **Add a Task**
   - Enter task title and click "Add Task"
   - Optionally set priority and due date

2. **Manage Tasks**
   - Check boxes to mark tasks as complete
   - Edit task details as needed
   - Delete tasks you no longer need

3. **Filter & Search**
   - Use search bar to find specific tasks
   - Filter by status (Active,Completed,All)
   - Sort by priority or due date

4. **Persistent Storage**
   - Your tasks are saved automatically
   - Data persists even after closing the browser
